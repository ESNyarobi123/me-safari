# Local Development Runbook

**Product:** Me and Adventure Safaris (M&A Safaris)  
**Architecture:** Monorepo (NestJS/Fastify API, BullMQ Worker, Expo Native App, Next.js Static Landing Page)  
**Database:** PostgreSQL 17 on Port `5433` | Redis on Port `6380` | Mailpit on Port `1025`/`8025`

---

## 1. Prerequisites

- **Node.js:** Node.js 24 LTS (pinned `>=24.21.0 <25`)
- **Package Manager:** `pnpm@12.11.2`
- **Container Engine:** Docker and Docker Compose (v2)
- **Native Mobile SDKs:** Android Studio / Emulator (or physical device with Expo Go/Dev Client), macOS/Xcode (optional for iOS Simulator)

---

## 2. Port Mapping and Local Infrastructure

| Service | Host Port | Protocol | Purpose |
|---|---|---|---|
| **Fastify REST API** | `4000` | HTTP | Core business API `/v1`, OpenAPI docs `/v1/docs` |
| **Next.js Landing Web**| `3000` | HTTP | Static frontend landing page |
| **Expo Metro Bundler** | `8081` | HTTP / WS | React Native bundler for mobile application |
| **PostgreSQL 17** | `5433` | TCP / PG | Primary relational database (`ma_safaris` & `ma_safaris_test`) |
| **Redis 7** | `6380` | TCP / Redis | BullMQ durable queue backend and caching |
| **Mailpit Web UI** | `8025` | HTTP | Local inbox to inspect outgoing verification/receipt emails |
| **Mailpit SMTP Sink** | `1025` | TCP / SMTP | Development email trap (no external emails sent) |

## 3. First-Time Setup Sequence

Run the following commands in the project root:

```bash
# 1. Install dependencies across all monorepo packages
pnpm install

# 2. Initialize local environment and generate local secrets if missing
pnpm setup:local

# 3. Start PostgreSQL 17, Redis, and Mailpit containers
pnpm infra:up

# 4. Generate Prisma client
pnpm db:generate

# 5. Run database migrations (including btree_gist extension and exclusion constraints)
pnpm db:migrate

# 6. Seed demo catalog, destinations, vehicles, staff, and initial accounts
pnpm db:seed

# 7. Generate OpenAPI 3 specification and TypeScript client SDK
pnpm contracts:generate
```

---

## 4. Running the Development System

Run these services in separate terminal tabs, or via your process manager:

### Terminal 1: REST API
```bash
pnpm dev:api
```
- Available at `http://127.0.0.1:4000/v1`
- Swagger UI available at `http://127.0.0.1:4000/v1/docs`
- Health check at `http://127.0.0.1:4000/v1/health/ready`

### Terminal 2: Background Worker
```bash
pnpm dev:worker
```
- Dispatches outbox events (receipt generation, notifications, emails)
- Manages reconciliation, quote expiration, and async export jobs

### Terminal 3: Public Landing Web
```bash
pnpm dev:web
```
- Available at `http://localhost:3000`
- Interactive 24-screen iPhone presentation covering all 4 roles

### Terminal 4: Native Mobile App
```bash
pnpm dev:mobile
```
- Starts Expo Metro development bundler on port 8081
- Press `a` for Android Emulator, `i` for iOS Simulator, or scan QR code with Expo Go

## 6. Verification and Health Checks

To verify system integrity and ensure all services are healthy:

```bash
# Run the local health inspection script
pnpm verify:local

# Run the complete test suite
pnpm test:unit
pnpm test:integration
pnpm test:e2e:api

# Run mobile and web test suites
pnpm --filter @ma-safaris/mobile test
pnpm --filter @ma/web test
```

## 7. Database Backup and Restoration

```bash
# Create a timestamped SQL dump in ./var/backups/
pnpm backup:local

# Restore from the latest dump or specify a file path
pnpm restore:local ./var/backups/backup-2026-10-11.sql
```
